# Creative-Academy-Task2
A simple, responsive landing page for an online learning platform built with HTML5 and CSS3.
About the Project
Creative Academy is a clean, modern landing page that showcases an academy's popular courses. It features a hero section with a background image, a navigation bar, course cards, and a footer. The design is fully responsive and works on both desktop and mobile devices.

# Features
Responsive Navbar — collapses into a column layout on mobile screens
Hero Section — full-width background image with a gradient overlay, headline, and call-to-action button
Smooth Scrolling — anchor links scroll smoothly to page sections
Course Cards — three cards with hover effects (lift + shadow) and gradient backgrounds
Mobile-Friendly — media queries adjust font sizes and layout for screens under 768px.
Hover Animations — buttons and cards respond to hover with color and transform transitions.

# Built With
HTML5 — semantic markup
CSS3 — Flexbox, media queries, transitions, gradients
Google Fonts — Inter font family
